# OOPLab4 — Satellite Management System

## Опис

Програма реалізує клас `Satellite` з характеристиками (назва, тип, висота
орбіти, дата запуску, потужність передавача, стан активності, рівень
пального, категорія орбіти) та поведінкою (передача даних, перемикання
живлення, зміна висоти орбіти, симуляція природного зниження орбіти).

Порівняно з Lab-3, до класу додано статичні члени: лічильник коректно
створених супутників (`Count`), лічильник експериментальних супутників
(`ExpCount`, використовується для нумерації їхніх назв) та сумарну витрату
пального (`UsedFuel`). Додано статичний метод розрахунку пального для
переміщення між двома висотами (`CalculateFuel`), методи `Parse` та
`TryParse` для створення супутника з рядка формату
`назва; тип; висота; дата`, а також перевизначений `ToString()`, який
повертає супутника у тому самому форматі.

## Функціонал

- Додавання об'єкта: вручну (повний конструктор), тестовий супутник за
  замовчуванням, випадково обраний конструктор, а також введення одним
  рядком (через `TryParse`), з обмеженням кількості N
- Перегляд усіх об'єктів у табличній формі зі статистикою (кількість
  супутників, кількість експериментальних, загальна витрата пального)
- Пошук за типом або назвою
- Демонстрація поведінки об'єкта, включно з усіма версіями перевантаженого
  методу `AdjustAltitude`
- Видалення за номером або за типом
- Демонстрація static-методів (статистика й розрахунок пального між
  орбітами)

## Формат рядка для додавання через TryParse

```
назва; тип; висота; дата
```

Приклад: `Alpha-1; Communication; 500; 15.03.2020`

Розділювач — крапка з комою та один пробіл. Тип можна вказати текстом
(`Communication`, `Weather`, `Scientific`, `Military`) або числом 1-4.
Дата — у форматі `dd.MM.yyyy`.

## Структура проєкту

- `Program.cs` — точка входу, меню, введення й обробка виключень
- `Satellite.cs` — клас супутника з конструкторами, властивостями,
  статичними членами та перевантаженими методами
- `SType.cs` — enum типів супутників
